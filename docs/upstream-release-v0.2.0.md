# Upstream collections release v0.2.0

The owner requested Matt Pocock, Poteto and other collections in the public kit.
This release includes112 main source skill packages: six learning entries,
39 Matt Pocock packages,58 main Poteto packages and9 Theo packages. Default
rstack discovery enables104 entries. Eight Matt in-progress drafts stay
reference-only; the pinned software-factory draft has malformed upstream YAML.
Three Benny automation helper manifests are also preserved as supporting source,
not part of the main58 Poteto skill count or enabled discovery roots.

All three added snapshots carry MIT notices and recorded source commits. The773
imported files are hash-verified and unmodified. Existing LearnHarness retains its
AGPL-3.0-only terms. See upstream-sources.json and upstream-compatibility.md.

The full Linux suite passed65 tests. New checks cover qualified lookup, family
search, default discovery roots, refusing bare-name collisions, changed/unlisted
source detection and path traversal. Metadata,26 workflow contracts, authored
local links and source integrity checks pass. Authored whitespace checks pass;
four upstream whitespace warnings are deliberately retained with original bytes.

The installer still owns six entry links in each client root,12 total. Additional
collections are available through rstack from vendor/. Native slash-command
registration, upstream plugin/hook/automation activation, third-party runtimes,
clean-Mac provider discovery and actual leaf workflows are not established by
this package test. Nothing broadens project or external-action permissions.
