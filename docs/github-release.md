# GitHub learning release v0.1.0

Published at the owner's explicit request on November9,2026. This release contains
six allowlisted packages and preserves the original attribution and imported
license notices. LearnHarness remains unmodified AGPL-3.0-only; Socratic Tutor
retains MIT. No private inventories, course inputs or account material is included.

The full Linux suite passed57 tests. Checks cover discovery/collisions/drift,
installer preflight/repeat/removal, source manifests and study-queue behavior.
The package check initially rejected two oversized unmodified LearnHarness files;
its authored-file size gate now exempts only upstream manifest entries whose
bytes still match their recorded hash. Imported source/license files were not
split or changed. Repository metadata, local links and26 workflow contracts pass.
A Mac path-alias assertion was normalized in the installer test; current six-skill
Mac/T3 discovery has not been exercised by this release. Earlier three-package
Mac evidence in mecg-release-verification.md has narrower scope.

INSTALL_WITH_AI.md documents an AI reading this GitHub source, cloning a pinned
release, inspecting the installer and verifying12 owned links across two local
skill roots. It does not require a reader-owned GitHub repo or public credentials.
Leaf workflows and learning gains are not established by package installation.
