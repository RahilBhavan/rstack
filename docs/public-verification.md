## Distribution review

The selection is the previously published, reviewed 104 enabled entries: rstack,
five learning leaves and 98 active Matt Pocock/Poteto/Theo leaves. No host cache or
private project skill is a source root. All upstream files match the pinned source
manifests, including complete parent resources and original notices. Imported
learning files match their existing exam/tutor manifests. The portable bundle
preserves every resource byte, including binary assets. Only nested entry filenames
change to instructions.md. Eight experimental drafts remain reference-only.

MIT notices for all three upstream collections are included in licenses/ and their
source trees. LearnHarness retains its AGPL-3.0-only license and complete unmodified
source; the matching release source ZIP preserves original layouts. Rstack's root
MIT notice does not replace those licenses. Personal paths/account markers are
rejected by the builder, in addition to selecting only already public source trees.
The full installed private inventory is never part of these release assets.

## Limits

Linux/Python behavior was exercised. Mac/Windows filesystem clients and actual
ChatGPT/Claude account uploads were not exercised. The plugin archive follows the
portable schema layout, with a Claude compatibility manifest; no public-directory
submission or approval is claimed. Independent routing checks are not execution of
all 103 leaf workflows. Account access, paid providers and runtime-specific tools
remain per-workflow dependencies. No recurring automation or live integration was
activated. The original dirty local repository was preserved; the release was built
from a separate public checkout.
