# Rstack

For “orient me”, “onboard me”, “getting started”, or a first-use tour, follow
[orientation](references/orientation.md) before browsing the index. Skip questions
already answered and move directly to a supplied goal. Orientation is optional.

Use this self-contained library to complete the user's task. Start with the
[index](references/index.md), or search with `python3 scripts/find.py "task words"`
using the actual path relative to this file. Python is optional for reading skills;
the index and all instructions can be read directly. Load only relevant entries.

Choose one lead workflow. Add companions only for a concrete requirement. Use the
exact author-qualified ID when names overlap. Read the selected `instructions.md`
and only the supporting resources needed for the task. Paths within each leaf are
relative to its folder. Entry filenames were changed from `SKILL.md` to
`instructions.md`; resolve literal references to those entry files accordingly.
Consult [compatibility](references/compatibility.md) before following runtime-specific
steps. The bundled source includes experimental drafts as references; these are
excluded from the index. Never route to them as enabled workflows.

The user's instructions, current project rules and existing authorizations retain
priority. Source copies may describe Claude, Cursor, T3 or particular model
providers: use equivalent local tools only after verifying their behavior and
preserving required independence, review gates and repair limits. If no equivalent
exists, name the missing capability and continue useful independent work. Never
claim a model, connector, account, app or workflow is available merely because its
instructions are bundled. Do not install hooks or recurring automation implicitly.

Before running scripts, inspect their inputs, dependencies and write destinations.
Keep user data outside the installed library. Evidence and source claims remain
distinct from observations. Execute authorized work, check observable behavior and
report what passed and what remains unverified. Publication, messages, purchases,
account changes and merging require the user's authority for the actual action.

For learning, use socratic-tutor for a single tutoring session; use study-loop for
multi-session review, exam-prep for format-driven study and practice-exam-factory
for exam production. LearnHarness history is optional and requires its separate app.
When a selected workflow needs independent agents and none exist in this client,
leave that gate pending rather than simulating multiple independent reviewers.
